# 中英术语

| 中文 | English | 用法 |
| --- | --- | --- |
| 黏滞 | viscosity | 书名及中心概念 |
| 技术黏滞 | technological viscosity | 技术引发现实状态转移时的广义阻力 |
| 广义黏滞 | generalized viscosity | 模型或框架中的总称 |
| 资源势垒 | resource barriers | R；材料、能量、设备与资本的进入条件 |
| 时间刚性 | temporal rigidity | T |
| 拓扑耦合 | topological coupling | G；正文先用依赖关系解释 |
| 表示空间 | representational space | 文本、图像、模型等内部表示 |
| 现实状态转移 | real-world state transition | 行文中也可写 actual change |
| 阻尼 | damping | 具体模型沿用物理含义 |
| 阻尼本体论 | an ontology of damping | 后果与边界的哲学讨论 |
| 验证 | verification / validation | 形式性质用verification；实用充分性用validation，避免机械一词贯穿 |
| 确认 | confirmation / grounds for reliance | 按上下文决定 |
| 准入 | authorization / acceptance | 行动权限和验收分别处理 |
| 承担后果 | bear the consequences | 不生造概念词 |
| 承责 | accountability | 可追索的责任结构 |
| 后果回流 | consequences returning to the decision maker | 图中可简写 return path |
| 承受者 | the party that bears the consequences | 视主体而定 |
| 承受闭合 | closure of the consequence-bearing boundary | 行动与后果被同一责任边界接住 |
| 切肤之痛 | skin in the game | Taleb用语 |
| 主体性 | agency | 形成、修订与执行自身立场的能力 |
| 价值证明 | evidence of value / recognition of worth | 根据证据与制度两个层次选词 |
| 意义 | meaning | 与purpose、recognition按上下文区分 |
| 形态计算 | morphological computation | 保留领域术语 |
| 身体封装 | embodiment as an integrated system | 身体作为材料、几何与反馈的整合系统 |
| 演化摊销 | costs amortized through evolution | 能力形成成本在长期使用中分摊 |
| 世界模型 | world model | 通用术语 |
| 可干预压缩 | compression that supports intervention | 正文短称intervention-ready compression |
| 算力 | compute / computing capacity | 根据总量与能力区分 |
| 低空经济 | low-altitude aviation / low-altitude air mobility | 按航空、运行与服务语境表达 |
| 地面交通 | ground transport | transportation用于美国交通语境 |
| 外卖骑手 | food-delivery courier | 英语改写依任务采用包裹配送、仓储与出行等场景 |
| 生物反馈 | biological feedback | 生命系统的调节与适应反馈 |
| 剪切增稠 | shear thickening | 流变学原义与广义类比分别定义 |
| 稳定流态 | a stable operating regime | 具体流动系统中再用flow regime |
